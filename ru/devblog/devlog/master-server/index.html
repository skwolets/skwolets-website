01

ЧТО ЗА МАСТЕР-СЕРВЕР?

Мастер-сервер — это диспетчер игровой инфраструктуры. Он знает, какие серверы работают, кто на них играет и какие из них доступны для подключения.

Каждый игровой сервер при запуске сообщает мастер-серверу:

01 СОСТОЯНИЕ

Сервер запущен и отвечает.

02 ИМЯ

Название и идентификатор сервера.

03 ИГРОКИ

Текущее количество игроков.

04 СЛОТЫ

Есть ли свободное место.

GAME SERVER Игровой сервер 30 / 60 игроков
HEARTBEAT
STATUS
MASTER Мастер-сервер актуальное состояние
SERVER LIST
CLIENT Игрок выбирает сервер
PRE-ALPHA

Все показанные материалы находятся на ранней стадии разработки. Визуальные элементы, интерфейс, механики и игровые системы могут измениться в процессе.

Представленные серверы являются тестовыми данными, сгенерированными исключительно для демонстрации работы браузера.

02

ПЕРВАЯ ВЕРСИЯ

Вот как система выглядит со стороны игрока. Мастер-сервер собирает информацию от игровых серверов и формирует актуальный список доступных подключений.

03

ПОЧЕМУ СОБСТВЕННАЯ СИСТЕМА?

Потому что чужие решения — это чужие ограничения.

Поэтому я создаю ключевую инфраструктуру с нуля. Без зависимости от сторонних решений. Без скрытых ограничений. С полным контролем над тем, как игроки получают доступ к игровому миру.

01 Какие серверы отображаются в списке.
02 Насколько быстро обновляется информация.
03 Как работает поиск, фильтры и сортировка.
04 Как происходит подключение.
БЕЗ ДОПОЛНИТЕЛЬНЫХ УЗЛОВ. Это не просто техническое решение — это фундамент для честной и прозрачной игры.
04

HEARTBEAT-СИСТЕМА

Как мастер-сервер понимает, что игровой сервер всё ещё работает?

Игровые серверы регулярно отправляют специальные сигналы — Heartbeat.

GAME SERVER Я работаю
HEARTBEAT
MASTER SERVER Сервер отвечает

[10:42:01] HEARTBEAT received

[10:42:01] server: ru-hardcore-01

[10:42:01] players: 30 / 60

[10:42:01] status: ONLINE

[10:42:01] server is healthy

Если сервер перестаёт отправлять Heartbeat, система понимает, что он больше недоступен, и автоматически убирает его из списка.

SERVER ONLINE → HEARTBEAT → MASTER → VISIBLE
05

Если сервер заполнен, игрок не получает просто ошибку подключения. Он может занять место в очереди.

АКТУАЛЬНЫЙ СПИСОК

Игрок видит реальные серверы и их актуальное состояние. Выключенные и недоступные серверы автоматически исчезают.

🔗

Контролируется весь путь — от обнаружения сервера до проверки доступности и свободного места.

ИТОГ

Это только первый этап развития системы.

Сейчас мастер-сервер уже умеет находить игровые серверы, отслеживать их состояние, управлять подключениями и приоритетами игроков.

В будущем система будет постепенно развиваться вместе с SKWOLETS — добавляя новые возможности для поиска серверов, работы с очередями, управления доступом и взаимодействия с сообществом.
